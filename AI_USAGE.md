| Модель | Инструмент / среда | Компонент | Характер помощи | Как проверено |

| GPT-6 | Codex | Комплект курса, `.gitignore`, `COURSE_KIT.md` | Проверка структуры, SHA-256 и актуальности ревизии; инструкция по сдаче | Контрольные суммы проверены командами `sha256sum -c`; ревизия сопоставлена с API курса. Самостоятельное повторение студентом ещё предстоит. |

| GPT-6 | Codex | `doctor.txt`, `environment.json` | Запуск диагностики установленного ROS, запись обнаруженных версий; удаление сетевых идентификаторов из отчёта | `ros2 doctor --report` завершился с кодом 0 вне песочницы; ОС проверена по `/etc/os-release`, RMW — через API rclpy. Настоящий teleop получил стрелку через PTY; движение проверено по координатам. CLI подтвердил ноды, типы, частоту, таймаут в домене 17 и восстановление в 16. Исходные выводы сохранены. Практическая выполнена агентом с существенной помощью ИИ; логи и измерения получены реальным запуском ROS, а не сгенерированы как ожидаемый вывод. Студенту предстоит самостоятельно повторить ручной опыт и объяснить результаты на защите; такое повторение пока не подтверждено. Полные чаты и личные промпты не приложены.
